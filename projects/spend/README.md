# Spend Project Profile

Reusable agent context for [Costility/Spend](https://github.com/muscaiu/spend).

- `AGENTS.md` describes the repository, commands, and coding boundaries.
- `RELEASE.md` is the authoritative release strategy.
- `commands/release.md` is the thin `/release` launcher.

When applying this profile to another repository, preserve the release phases and safety gates but replace Spend-specific package paths, checks, store identifiers, deployment provider, and version files with validated equivalents from that repository.
